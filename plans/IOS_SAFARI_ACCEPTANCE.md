## 用户侧连接准备

1. 使用支持数据传输的 USB 线连接 iPhone，解锁并确认“信任此电脑”；Mac 若出现允许连接提示也需确认。
2. 在 iPhone 的 Safari 高级设置中开启“远程自动化”。较新 iOS 的路径通常为
   “设置 → App → Safari → 高级”；旧版本从“设置 → Safari”进入。
   “网页检查器”可同时开启供调试使用。
3. 在 Mac Safari 开启“开发”菜单中的“允许远程自动化”；设置里的开发者选项需按实际 Safari 版本进入。
   系统如要求本机认证，由用户在系统界面完成。
4. 首次连接保持 iPhone 解锁，以便处理设备上的连接/自动化提示。

设置路径按实际系统界面核实，不以找不到某个旧版标签直接判定设备不支持。

## 自动化与设备观察分工

| 验收内容 | 执行方式与判定 |
| --- | --- |
| 全站主要入口：首页、Play/Daily/Weekly、Training/Solver、generator/checker | 先执行 iOS Safari 冒烟检查，再执行重点 Complete 回归；移动设备范围统一为 iOS |
| 教程、输入目标/重复/无效/奖励/extras、提示门槛、旋转与词路径回看 | 通过 WebDriver 的实际元素操作执行；不以注入进度代替玩家操作 |
| 刷新存档、原档/独立重玩、归档月份及未来日期限制 | 自动化；保留原有个人数据，选择隔离的验收来源和新测试存档 |
| 实际 iPhone 视口、页面溢出、键盘布局、截图 | 自动读取真实 CSS 视口并截图；一部 iPhone 不代表已覆盖全部 iPhone 尺寸 |
| 多标签合并、剪贴板、离线与更新 | 先探测实体驱动/设备是否支持需要的操作；仅将实际执行的项记录通过，不支持则保留待补验 |
| 系统分享面板打开/取消、真实手指快速折线、系统断网/后台恢复 | 视网页驱动能力与系统弹窗情况进行用户辅助验收；纯网页 WebDriver 不承诺能控制系统面板 |
| 跨午夜、VoiceOver、系统文字放大 | 需分别设计并执行实际场景；未执行时保持待验收，不调整用户设备日期伪造自然切日 |

WebDriver 触控操作成功只能证明程序化交互路径；真实手指体验另留记录。
系统分享只验证面板、预览、取消及回退，不向第三方发送内容。
优先使用隔离的可访问测试地址执行交互用例；正式域名默认执行页面/资源/API GET 复查。
2026-11-22 实测补充：实体 iPhone 访问预览域名/临时测试域名存在加载超时，而正式域名可正常加载。
本轮已授权真机测试因此允许在 Safari 隔离自动化会话中操作正式站的已发布历史题及 UUID 独立重玩，
仅影响该会话本机进度；不操作用户原有浏览器存档，不填写姓名或提交公开排行榜。该范围不等同于允许测试后端写入。
手机上的 localhost 指向手机自身，连接 USB 不会自动使 Mac 的 localhost 可用；
开始前需确认手机能访问选定的 HTTPS 测试地址，离线用例同时确认安全上下文和 Service Worker。
