# WordGrid Complete 真机验收手册

## 1. 测试信息

- 正式测试地址：https://wordgrid.games/complete/
- 测试版本：2026-10-14 交互升级（渐进式提示、旋转、路径回看、分享、首玩引导）。
- 使用 Safari / Chrome 直接打开 HTTPS 地址，不需要连接同一 Wi-Fi。
- 建议至少覆盖 iPhone Safari 和 Android Chrome，记录系统及浏览器版本。
- 使用该地址下没有进度的新浏览器配置开始测试；不要清除个人浏览器全部数据。隐私模式可测试玩法，但持久保存须在普通模式另测。
- 每日棋盘在 UTC+8 零点切换。下文固定坐标、答案和分数仅适用于页面日期 2026-10-14，且初始为 0/10、0 分。
- 日期变化时，通用交互用例仍有效，但固定答案和分数不得作为失败依据，应重新准备当天用例。跨零点测试需记录前后日期。
- 本文预期结果不是测试结论。测试人员填写实际结果并附截图/录屏。

## 2. 当天棋盘与坐标

坐标均为屏幕从上到下的行、从左到右的列，从 1 开始；除明确说明外，棋盘角度为 0°。

```text
      列1 列2 列3 列4
行1    E   D   N   U
行2    R   S   T   A
行3    N   S   D   N
行4    B   E   A   O
```

## 3. 首玩引导（T01）

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 新浏览器打开页面 | 出现 Quick start / 1 of 3；日常棋盘、输入及提示禁用 |
| 2 | 在练习棋盘拖动 R → A → T → E 后松手 | 成功提示，出现 Next example；不需要再点提交 |
| 3 | 下一关连接 L → A → T → E | 斜向 L → A 有效，练习成功 |
| 4 | 第三关点 R、A，点 Undo，再点 A、T、E，点 Submit tutorial path | 撤销有效，出现 Start today's board |
| 5 | 完成引导 | 日常游戏可操作，仍为 0/10、0 分 |
| 6 | 刷新，再点 Quick start | 不自动出现引导，但能手动重新打开；Skip tutorial 可退出 |

触摸过程中不应滚动页面、选中文本或一次提交多次。

## 4. 拖动、点击、撤销与错误反馈（T02）

### 4.1 连续触摸拖动

按住 E(4,2)，不松手经过 A(4,3) → S(3,2) → T(2,3)，最后松手。

- 选中格、顺序编号、连线随手指更新。
- 自动提交 EAST，显示 EAST: target found!。
- 进度 1/10，2 分。重复找 EAST 不增加进度或分数。
- 棋盘内拖动不应滚动页面；棋盘外仍能滚动。

### 4.2 点击与撤销

点 R(2,1) → E(1,1) → S(2,2)，点 Undo，再点 S(2,2) → T(2,3)，点 Submit path。

- Undo 只删除末尾 S，保留 RE。
- REST 成功；进度 2/10，4 分。
- Start counts 解锁，First letters 和揭词仍禁用。

### 4.3 非相邻及重复格

- 空路径点 E(1,1)，再点 O(4,4)：O 不加入，反馈必须选择相邻格；Clear 清空且分数不变。
- 空路径点 R(2,1) → E(1,1) → S(2,2) → R(2,1)：最后 R 被拒绝，反馈每格只能使用一次，保留 RES。
- 从 RES 回到前一个 E：应撤销末尾 S，保留 RE，而非报重复格错误。
- 清空后再进行一条新拖动：不能继承上一条点击路径。

## 5. 渐进式提示与零分揭词（T03）

先确认已找到 EAST、REST，进度 2/10、4 分。用 Type a word 输入指定词并点 Find。

| 操作 | 预期进度 | 预期分数及反馈 |
| --- | --- | --- |
| 点 Start counts | 2/10 | 4 分；棋盘出现剩余词起点数量角标 |
| 输入 SAND | 3/10 | 6 分 |
| 输入 NEST | 4/10 | 8 分；First letters 解锁 |
| 点 First letters | 4/10 | 未找到词仅显示首字母和隐藏占位 |
| 点 Hide hints | 4/10 | 数量角标、首字母隐藏；提示使用记录仍保留 |
| 输入 NESTS | 5/10 | 12 分；揭词仍禁用 |
| 输入 UNDERSTAND | 6/10 | 26 分；揭词解锁 |
| 点 Reveal one target (0 points) | 7/10 | 本流程揭开 BEST，词旁有 *；仍为 26 分 |
| 刷新页面 | 7/10 | 26 分、BEST 的 * 和提示使用记录保留 |

数量角标表示有多少剩余目标词可以从该格开始，不是经过该格的词数；同一个词可从不同格起步。

## 6. 旋转、回看与坐标映射（T04）

在 7/10、26 分时，点击已找到的 UNDERSTAND。

1. 显示连线、顺序编号 1～10，按顺序读为 UNDERSTAND。
2. 连续旋转四次：90° → 180° → 270° → 0°。
3. 连线与编号随字母一起旋转，进度和分数始终不变，四次后恢复原棋盘。
4. 没有可靠释义来源的长词显示暂无来源释义说明，不提供编造释义；已有本站词条的词提供有效详情链接。
5. 再旋转至 90°，关闭回看，按以下屏幕坐标连接并提交：

```text
R(1,3) → E(1,4) → S(2,3) → T(3,3) → S(2,2)
```

预期 RESTS 成功，8/10、30 分；不能出现显示字母与实际选中字母不一致。

## 7. 完成、奖励词和保存（T05）

继续用输入框提交：

| 输入 | 预期进度 | 预期分数 |
| --- | --- | --- |
| SANDS | 9/10 | 34 |
| UNDERSTANDS | 10/10 | 46 |
| ERNE | 10/10，1 个奖励词 | 48 |
| ERNES | 10/10，2 个奖励词 | 52 |

- 10/10 后显示完成状态，揭词按钮禁用。
- 奖励词不改变目标完成比例，点击奖励词可回看路径。
- 普通模式下刷新、关页重开，保留 10/10、52 分、2 个奖励词、1 个揭词标记。
- 使用相同浏览器和相同域名；不同域名的进度不互通。

## 8. HTTPS 分享、复制与取消（T06）

点击 Preview text，严格按上述流程时预期文本为：

```text
WordGrid Complete - 2026-10-14
10/10 targets (100%)
2 bonus words
Hints used / 1 revealed
https://wordgrid.games/complete/
```

| 操作 | 预期结果 |
| --- | --- |
| Copy result，粘贴到备忘录 | 与预览一致，无答案、棋盘或路径 |
| Share result | 支持系统分享的浏览器弹出原生分享面板 |
| 取消分享 | 无崩溃、不丢进度，反馈分享已取消 |
| 不支持系统分享 | 尝试复制；失败时显示可手动复制的文本和说明 |
| 开着预览再增加进度（另一个新测试配置） | 文本随进度更新，不保留旧成绩 |

无需实际发送给第三方。取消分享不是测试失败；不支持原生分享时，回退路径正常即通过。

## 9. 布局与触摸体验（T07）

竖屏、横屏、浅色与深色模式分别检查：

- 无横向滚动、按钮截断、长词撑破卡片。
- 连线与格子中心对齐，编号可辨识。
- 手指快速、慢速连续拖动都能选择相邻格；松手只提交一次。
- 手指移出棋盘或系统中断手势时，无卡死；可清空并重新选择。
- 键盘弹出后输入框与 Find 按钮可见、可操作。
- 页面正常上下滚动，棋盘区域内拖动不带动页面。
