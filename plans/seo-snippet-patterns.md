# SEO Snippet Patterns

Use these patterns when adding or refreshing WordGrid pages. Keep snippets clear for users first, then align them with observed Webmaster and GSC queries.

## Game Mode Pages

Title pattern:

`Primary Action - Main Differentiator`

Examples:

- `Play Word Grid Online Free - Instant 4x4, 5x5, 6x6 Game`
- `Daily Word Grid Puzzle - Play Today's Free 4x4 Board`

Description pattern:

`Play/use [page type] free. Mention no download/sign-up, board size or mode, and the concrete reason to click.`

## Tool Pages

Title pattern:

`Tool Keyword: Free Supporting Keyword Online`

Examples:

- `Boggle Solver: Free Word Grid Word Finder Online`

Description pattern:

`Use this free [tool] to [specific output]. Mention input format, result format, and post-play/review use where relevant.`

## Beginner Guides

Title pattern:

`Topic for Audience: Outcome or Use Case`

Examples:

- `Boggle Rules for Beginners: How to Play, Score, and Win`
- `Boggle Rules for Kids: Easy Rules for Children and Classrooms`

Description pattern:

`Learn [topic] fast with [specific subtopics]. Mention examples, rules, scoring, or audience fit.`

## Vocabulary Guides

Title pattern:

`Vocabulary Topic: Organization Method and Benefit`

Examples:

- `Boggle Word List: Common Words by Letter and Pattern`
- `Boggle Dictionary: Valid Words, Word Lists, and Lookup Rules`

Description pattern:

`Browse/use [resource] by [organization method] so you can [gameplay benefit].`

## Comparison Guides

Title pattern:

`A vs B: Key Differences for User Choice`

Description pattern:

`Compare [A] and [B] by rules, gameplay, scoring, and when to choose each one.`

## Quality Rules

- Keep the primary query near the front of the title.
- Keep title copy natural; do not list every keyword variant.
- Put the click reason in the description: free, instant, no download, daily, solver, scoring, kids/classroom, or practice.
- Keep descriptions compact enough that the core offer appears even if search engines truncate them.
- Align the H1 with the title, but make the H1 read well on the page.
- Use descriptive internal anchors that match target page intent.
